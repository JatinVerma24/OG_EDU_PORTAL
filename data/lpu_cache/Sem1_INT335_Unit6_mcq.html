1 What is design iteration?

Design Iteration and Product Re-Design Easy
A. Creating one design and never changing it
B. Replacing the entire project team
C. Selling a product without testing it
D. Repeating design steps to improve a product

Correct Answer: Repeating design steps to improve a product

Explanation:

Design iteration involves repeatedly testing and improving a product based on what is learned.

Incorrect! Try again.

2 What is the main purpose of product re-design?

Design Iteration and Product Re-Design Easy
A. To improve an existing product
B. To duplicate a competitor's product exactly
C. To remove every product feature
D. To avoid studying user needs

Correct Answer: To improve an existing product

Explanation:

Product re-design changes an existing product to improve its usability, value, appearance, or performance.

Incorrect! Try again.

3 Which activity is a basic part of design iteration?

Principles of Design Iteration Easy
A. Testing a prototype
B. Finalizing the first idea
C. Avoiding user contact
D. Ignoring test results

Correct Answer: Testing a prototype

Explanation:

Testing a prototype helps designers identify strengths, problems, and opportunities for improvement.

Incorrect! Try again.

4 What should designers generally do after identifying a problem during testing?

Principles of Design Iteration Easy
A. Stop the project immediately
B. Change the target user randomly
C. Revise the design and test again
D. Hide the test results

Correct Answer: Revise the design and test again

Explanation:

Iteration uses test findings to revise the design before another round of testing.

Incorrect! Try again.

5 Why do designers collect user feedback?

User Feedback Analysis Easy

Correct Answer: To understand the user's experience

User feedback reveals how people experience a product and what may need improvement.

Incorrect! Try again.

6 Which feedback is most useful for improving a product?

User Feedback Analysis Easy

Correct Answer: A specific description of a usability problem

Explanation:

Specific feedback about an actual experience helps designers identify and address a clear problem.

41 A prototype reduces task-completion time by 30% in a controlled test, but users report that it feels less trustworthy than the original. Which redesign decision is most defensible?

42 A team changes five major features between two usability tests and observes improved satisfaction. Why is this iteration method strategically weak?

Principles of Design Iteration Hard
A. It guarantees that participants will prefer the newer prototype
B. It makes it difficult to attribute observed effects to individual changes
C. It prevents the team from testing visual appeal in later studies
D. It limits the number of stakeholders who can review the prototype

Correct Answer: It makes it difficult to attribute observed effects to individual changes

Explanation:

Changing many variables at once reduces diagnostic value. The team may know the outcome changed but cannot determine which design decision caused it or which should be retained.

Incorrect! Try again.

43 In interviews, eight users request an additional feature, while two users reveal that the current workflow causes critical errors. Which interpretation should guide the next iteration?

User Feedback Analysis Hard
A. Ignore both findings until a statistically representative survey is completed
B. Prioritize the requested feature because it has broader numerical support
C. Prioritize the critical errors because severity outweighs simple frequency
D. Average both findings and implement a smaller version of each

Correct Answer: Prioritize the critical errors because severity outweighs simple frequency

Explanation:

Feedback should be weighted by impact, not counted mechanically. A less frequent problem can deserve priority when it creates serious harm, failure, or loss of core task performance.

D. Simplify the settings workflow before expanding customization options

Correct Answer: Simplify the settings workflow before expanding customization options

Explanation:

Strategic Pivoting and Continuous Improvement Hard
