1 What is JavaScript primarily used for in web development?

Introduction to JavaScript Easy
A. Adding interactivity to web pages
B. Managing files on a web server
C. Styling the appearance of web pages
D. Defining the structure of web pages

Correct Answer: Adding interactivity to web pages

Explanation:

JavaScript adds dynamic behavior and interactivity to web pages.

2 Which HTML element is used to include JavaScript code in a web page?

Introduction to JavaScript Easy
A. <script>
B. <meta>
C. <link>
D. <style>

Correct Answer: <script>

Explanation:

The <script> element embeds JavaScript code or references an external JavaScript file.

3 Which keyword declares a block-scoped variable that can be reassigned?

Variables and Constants Easy
A. static
B. let
C. define
D. const

Variables and Constants Easy

45 What are the final values of x and y?

JAVASCRIPT
