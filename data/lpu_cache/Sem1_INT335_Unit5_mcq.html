A. Increase breadcrumb contrast while retaining the current system hierarchy
B. Remove breadcrumbs and rely on browser history for contextual navigation
C. Replace breadcrumbs with a persistent button returning directly to Home
D. Reflect the user hierarchy, such as Client > Quarter > Report

Correct Answer: Reflect the user hierarchy, such as Client > Quarter > Report

Explanation:

Navigation should support the user's mental model and related-work structure. A client-and-quarter hierarchy provides meaningful context and enables movement among conceptually related reports.

59 A custom dropdown can be reached with Tab, but pressing arrow keys scrolls the page, a screen reader announces only "button," and focus disappears after selection. Which remediation is most complete?

Accessibility in Digital Products Hard
A. Increase color contrast and add visible hover styling to each option
B. Add a tooltip explaining that mouse input is recommended for selection
C. Implement the expected keyboard model, roles, names, states, and focus handling
D. Expose all options in placeholder text and preserve the current interaction

Correct Answer: Implement the expected keyboard model, roles, names, states, and focus handling

Explanation:

An accessible custom dropdown needs semantic identification, an accessible name, communicated state, standard keyboard behavior, and predictable focus management. Visual changes alone do not resolve these failures.
