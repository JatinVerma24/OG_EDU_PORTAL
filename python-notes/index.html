Unit 1

🚀 Variables, Expressions & Statements

“ A variable is a named container that holds a value—the foundation of all programming logic. ”

👉 What is a Variable?

  • 📦 A variable is a named storage container. When you write age = 20, you are telling Python: "Create a box, label it 'age', and put the number 20 inside it."
  • 🏷️ The name is on the left, the value is on the right. The = sign means "store this value".
  • 🔄 You can change a variable's value anytime. The old value is simply replaced.
  • 🧩 Variable names should be descriptive. Use age instead of just x.
📄 variables.py
# Store values in variables
name = "Alice"
age = 20
print(name, age)
📄 update.py
# Update a variable
score = 10
score = 50
print(score)  # Prints 50

👉 Naming Rules for Variables

  • ✅ Names can contain letters, numbers, and underscores ( _ ).
  • 🚫 Names CANNOT start with a number.
  • 🚫 Names CANNOT have spaces. Use an underscore instead.
  • 🔡 Python is case-sensitive. age and Age are different.
📄 naming.py
# Good variable names
user_name = "Bob"
total_score = 95
print(user_name)
📄 case.py
# Case sensitivity
name = "Alice"
Name = "Bob"
print(name, Name)

👉 The print() Function

  • 🖨️ print() shows output on the screen. It is how your program talks to you.
  • 📝 You can print text, variables, or numbers. Just put them inside the parentheses.
  • ➕ You can print multiple things at once. Separate them with commas.
📄 print.py
# Printing text and variables
name = "Alice"
print("Hello")
print(name)
📄 print_multiple.py
# Printing multiple items
age = 20
print("I am", age, "years old.")

👉 Understanding f-strings (Formatted Strings)

  • ✨ The f in f"..." stands for "formatted." It tells Python to format the string with variables inside.
  • 🔤 Inside an f-string, use curly braces {} to insert variables. Example: f"Hello {name}"
  • 💡 Variables inside {} are replaced with their actual values. NOT printed as literal text.
  • ⚡ f-strings are cleaner and easier to read than other string joining methods.
  • 🎯 You can put expressions inside {}, not just variable names. Example: f"Sum: {5 + 3}"
  • 💾 f-strings must start with the letter f before the opening quote. Write f"...", not "..."
📄 fstring_basic.py
# Basic f-string with one variable
name = "Alice"
print(f"Hello, {name}!")  # Hello, Alice!
📄 fstring_multiple.py
# f-string with multiple variables
name = "Bob"
age = 25
print(f"My name is {name} and I'm {age} years old.")
📄 fstring_calc.py
# f-string with calculations inside
a = 10
b = 5
print(f"Sum: {a + b}")        # Sum: 15
print(f"Product: {a * b}")   # Product: 50
📄 without_fstring.py
# Without f-string (harder to read)
name = "Alice"
age = 25
# The old way (messier)
print("My name is " + name + " and I'm " + str(age) + " years old.")
# The f-string way (cleaner)
print(f"My name is {name} and I'm {age} years old.")

👉 Data Types — What Kind of Data Can You Store?

  • 🔢 Integer (int) — Whole numbers. Like 5 or 100.
  • 🌊 Float — Decimal numbers. Like 3.14 or 9.99.
  • 📝 String (str) — Text wrapped in quotes. Like "Hello".
  • ✅ Boolean (bool) — True or False. Like a light switch.

  • 📚 Follows standard math rules. Parentheses first, then Multiply/Divide, then Add/Subtract.

👉 Taking User Input

  • ⌨️ input() lets your program ask the user for data. It pauses and waits for the user to type and press Enter.

🔀 Conditional Statements

“ Every decision in your program starts with a condition—master if, elif, and else to control flow. ”

👉 Comparison Operators

  • ⚖️ == checks if two values are equal. Example: 5 == 5 gives True.
  • 🚫 != checks if two values are NOT equal. Example: 5 != 3 gives True.
  • 📊 > checks if the left value is bigger. Example: 10 > 3 gives True.
  • 📉 < checks if the left value is smaller. Example: 2 < 8 gives True.
  • 💡 All comparison operators always return either True or False.
📄 equal.py
# Equal == and Not Equal !=
print(5 == 5)   # True
print(5 != 3)   # True
print(5 != 5)   # False
📄 compare.py
# Greater and Less Than
a = 10
b = 5
print(a > b)   # True
print(a < b)   # False

👉 The if Statement

  • 🚦 if runs code ONLY if true.
  • 🔵 else runs if false.
  • 🔶 elif checks additional conditions.
📄 if_else.py
# Making a decision
age = 18
if age >= 18:
    print("Adult")
else:
    print("Minor")
📄 elif.py
# Multiple choices
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

👉 Logical Operators

  • ✅ and — BOTH must be True.
  • 🔓 or — AT LEAST ONE must be True.
  • 🔄 not — Reverses True/False.
📄 logic.py
# Combining rules
is_sunny = True
has_time = True
if is_sunny and has_time:
    print("Go to park!")

  • 📦 Return multiple values as a tuple.
  • 🔀 Unpack them into separate variables.

👉 Scope: Local vs Global

  • 🔒 Local variables only exist inside functions.
  • 🌍 Global variables exist throughout the program.
  • ⚠️ Use global keyword to modify global variables in functions.
  • 🎯 Local scope is usually safer and cleaner.
📄 local_scope.py
# Local variable inside function

    print(x)

# print(x)   # Error! x doesn't exist outside
📄 global_scope.py
# Global variable
counter = 0

def increment():
    global counter
    counter += 1

increment()
increment()
print(counter)  # 2

🎯 Strings & Text

“ Strings are the language of text—master them to build powerful text-processing applications. ”

👉 String Basics

  • 📝 A string is a sequence of characters in quotes. Use single or double quotes.
  • 🔗 Strings can contain letters, numbers, spaces, and symbols.
  • 🎯 Strings are immutable — once created, they cannot be changed. You create new strings instead.
  • 📏 Use len() to find the length of a string.
📄 strings_basic.py
# Creating strings
name = "Alice"
greeting = 'Hello'
message = "Python is awesome!"
print(len(message))  # 20
📄 multiline.py
# Multi-line strings with triple quotes
story = """Once upon a time,
there was a programmer.
The end."""
print(story)

👉 Indexing and Negative Indexing

  • 💺 Start counting from 0 for positive indexing. First character is [0].
  • 🔙 Use negative indices to count from the end. Last character is [-1].
  • 🚫 Going out of bounds raises an IndexError.
📄 indexing.py
# Positive and negative indexing
word = "Python"
print(word[0])     # P
print(word[5])     # n
print(word[-1])    # n (last char)
print(word[-2])    # o (second to last)
📄 char_access.py
# Accessing characters
text = "Hello"
print(text[1])     # e
print(text[3])     # l
print(text[-3])    # l

👉 Slicing Strings

  • ✂️ Use [start:end] to slice — includes start, excludes end.
  • 🚀 Omit start to begin from 0: [:end]
  • 🏁 Omit end to go to the last character: [start:]
  • 📊 Use [start:end:step] to skip characters.
📄 slicing.py
# Basic slicing
word = "Python"
print(word[0:2])   # Py
print(word[2:5])   # tho
print(word[:3])    # Pyt
print(word[3:])    # hon
📄 step_slice.py
# Slicing with step
text = "ABCDEFGH"
print(text[::2])    # ACEG (every 2nd)
print(text[1::2])   # BDFH (start at 1, every 2nd)
print(text[::-1])   # HGFEDCBA (reverse)

👉 String Methods — Case Changes

  • 🔤 .upper() converts to UPPERCASE.
  • 🔡 .lower() converts to lowercase.
  • 📝 .title() capitalizes first letter of each word.
  • 🔄 .swapcase() swaps upper to lower and vice versa.
  • 💡 .capitalize() capitalizes only the first letter.
📄 case_methods.py
# Change string case
text = "hello World"
print(text.upper())       # HELLO WORLD
print(text.lower())       # hello world
print(text.title())       # Hello World
print(text.capitalize())  # Hello world
📄 swapcase.py
# Swap case
text = "PyThOn"
print(text.swapcase())  # pYtHoN

👉 String Methods — Finding & Replacing

  • 🔍 .find() returns the index of substring, or -1 if not found.
  • 📍 .index() is like find() but raises error if not found.
  • ✔️ .count() counts how many times a substring appears.
  • 🔄 .replace(old, new) replaces all occurrences.
  • ✅ .startswith()/.endswith() check the beginning/end.
📄 find_methods.py
# Finding substrings
text = "Hello World"
print(text.find("o"))       # 4 (first o)
print(text.find("xyz"))     # -1 (not found)
print(text.count("l"))      # 3 (three l's)
📄 replace_methods.py
# Replace and check
text = "Hello World"
print(text.replace("World", "Python"))  # Hello Python
print(text.startswith("Hello"))  # True
print(text.endswith("orld"))     # True

👉 String Methods — Splitting & Joining

  • ✂️ .split() breaks a string into a list by a delimiter.
  • 🔗 .join() combines a list into a single string.
  • 🧹 .strip() removes leading/trailing whitespace.
  • 🔲 .lstrip()/.rstrip() removes from left/right only.
📄 split_join.py
# Split and join
sentence = "Hello World Python"
words = sentence.split()          # ['Hello', 'World', 'Python']
joined = " ".join(words)           # 'Hello World Python'
csv = "apple,banana,cherry".split(",")  # ['apple', 'banana', 'cherry']
📄 strip.py
# Stripping whitespace
text = "  Hello World  "
print(text.strip())     # Hello World
print(text.lstrip())    # Hello World  
print(text.rstrip())    #   Hello World

👉 String Checking Methods

  • ✔️ .isalpha() checks if all characters are letters.
  • 🔢 .isdigit() checks if all characters are numbers.
  • 🔤 .isalnum() checks if all are letters or numbers.
  • 🔍 .isspace() checks if all are whitespace.
  • 📝 .isupper()/.islower() checks case.
  • 🎯 in operator checks if substring exists.

# Check string properties

👉 String Immutability

  • 🔒 Strings cannot be modified after creation.
  • 🆕 Methods create and return NEW strings.
  • 💾 You must reassign the variable to "change" it.
  • ⚡ This makes strings safe and predictable.

# String immutability
text = "hello"
# text[0] = "H"  # ERROR! Cannot change

# Methods return new strings

print(modified)   # ABC (new string)

👉 Escape Characters

  • 🎯 \n creates a new line.
  • 🔲 \t inserts a tab (indentation).
  • \🔸 \\ includes a backslash character.
  • 🔕 \\' or \\" includes quotes inside strings.
  • 🔄 Use raw strings r"text" to ignore escapes.
📄 escape.py
# Using escape characters
print("Line 1\nLine 2")     # Newline
print("Name\tAge")         # Tab
print("She said \"Hi!\"")  # Quotes
📄 raw_string.py

  • 🎯 You don't pass self manually — Python does it automatically.

👉 Instance Attributes vs Class Attributes

  • 👤 Instance attributes belong to individual objects. Set in __init__ with self.
  • 🏫 Class attributes belong to the whole class. Defined outside methods, shared by all instances.
  • 📊 Each object has its own copy of instance attributes. Changing one doesn't affect others.

print(cat.name)   # Whiskers (unchanged)
