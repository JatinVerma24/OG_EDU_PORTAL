Computer Networks Simplified: OSI Model, TCP/IP & Subnetting Guide

Computer Networks connects modern distributed software systems. This guide breaks down protocol architectures, network layers, socket connections, and CIDR subnet math.

1. The 7-Layer OSI Reference Model

2. TCP vs UDP & 3-Way Handshake

TCP (Transmission Control Protocol) is connection-oriented, reliable, and guarantees in-order packet delivery using acknowledgments and retransmissions. Establishing a TCP connection requires a 3-Way Handshake:

  1. SYN: Client sends a SYN packet with initial sequence number $x$.
  2. SYN-ACK: Server responds with SYN with sequence number $y$ and ACK $= x + 1$.
  3. ACK: Client responds with ACK $= y + 1$. The connection is now established.

UDP (User Datagram Protocol) is connectionless, lightweight, and transmits without handshakes or retransmissions, making it ideal for live video streaming, voice over IP (VoIP), and multiplayer gaming.

3. IPv4 Subnetting & CIDR Calculation

Subnetting divides a larger IP network into smaller, manageable subnet segments. For a network 192.168.1.0/26:

  • Subnet Mask: /26 means 26 network bits and $32 - 26 = 6$ host bits. Subnet mask = 255.255.255.192.
  • Total IP Addresses per Subnet: $2^6 = 64$ addresses.
  • Usable Host Addresses: $2^6 - 2 = 62$ hosts (subtracting the Network ID and the Directed Broadcast address).

4. Essential Network Protocols

  • DNS (Domain Name System): Resolves human-readable domain names (e.g. ogedu-portal.vercel.app) into machine IP addresses via recursive hierarchical queries.
  • DHCP (Dynamic Host Configuration Protocol): Automatically assigns IP addresses, subnet masks, and default gateways to joining clients using the DORA (Discover, Offer, Request, Acknowledge) process.

5. Frequently Asked Questions

Why is the maximum transmission unit (MTU) typically 1500 bytes on Ethernet?

1500 bytes balances network header overhead against packet retransmission costs and buffer constraints across standard Ethernet switching hardware.
